# bernardorohlfs.com

Personal site of Bernardo Cruz Rohlfs — a single-screen, interactive night sky.

A living starfield reacts to your cursor. Clicking launches fireworks. There are
a few secrets in the sky, and one in the console.

Built with Next.js and a zero-dependency Canvas 2D engine. Source lives in
[`my-app/`](my-app/).

🔗 Live: [https://bernardorohlfs.com](https://bernardorohlfs.com)
